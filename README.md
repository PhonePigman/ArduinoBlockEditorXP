【重要：Windows 10 / 11 をお使いの方へ】
Windows 10 または Windows 11 をお使いの場合は、本バージョン（.NET 3.5版）ではなく、
機能が充実した最新版（.NET 8ベース）のご利用を強くおすすめします。
最新版は以下のGitHubリポジトリからダウンロードいただけます。
https://github.com/PhonePigman/ArduinoBlockEditor


----------------------------------------------------------------
【本バージョンの動作環境】
本ソフトは、古いOS環境（Windows XP〜8.1）向けに用意された互換版です。

■ 対応OS:
  - Windows XP (SP2 / SP3) ※1
  - Windows 7 / 8 / 8.1
■ 必須ランタイム:
  - .NET Framework 3.5（セットアップ時に自動インストールされます）

※1 Windows XP でのご利用について
・Windows XP SP1 以前の環境では動作しません。SP2以降にアップデートしてください。
・インストール時に「Windows Installer 3.1」等の導入を求められた場合は、
  画面の指示に従ってOSのアップデートを行ってください。
  

----------------------------------------------------------------
【重要：Arduino IDE の準備について（古いOS向け）】
本ソフトで生成したコードをマイコンに書き込むには、別途「Arduino IDE」が必要です。

古いOS（Windows XP / 7 / 8 / 8.1）環境において、最も動作が軽量で安定性が高く、
今でも人気の名作バージョン「Arduino IDE 1.0.6」の使用を一律で推奨しています。
以下のURLより入手してください。
https://github.com/e-Gizmo/Arduino-1.0.6-IDE-Windows.git

【使い方】
1. 上記URLを開き、緑色の「Code」ボタン ⇒「Download ZIP」の順にクリックしてダウンロードします。
2. ダウンロードしたZIPファイルを解凍します。
3. フォルダ内にある「arduino.exe」を実行すれば、インストール不要でそのまま起動します。
